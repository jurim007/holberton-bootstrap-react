# Holberton Bootstrap React

Simple React project using Vite and react-bootstrap. Made as a Holberton School test project while learning React basics before moving on to databases.

## What's in it

- Home page with an About section
- Admin page that fetches user data from an API and lets you search by name
- Basic routing between Home and Admin using react-router-dom

## Stack

- React
- Vite
- react-bootstrap
- react-router-dom

## Running it

Needs Node 20.19+ or 22.12+.

```
npm install
npm run dev
```


Then open the local URL it gives you (usually http://localhost:5173).

## Data source

User data comes from [DummyJSON](https://dummyjson.com/users).
